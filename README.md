# 🚀 Job Portal Application

A modern Job Portal Web Application built using React.js, React Router, Bootstrap, Chart.js, and LocalStorage.

The platform allows candidates to search jobs, save jobs, apply for jobs, manage profiles, upload resumes, and track applications. It also provides an Admin Dashboard for managing jobs, users, applications, shortlisted candidates, rejected candidates, and analytics.

# ⚙️ Installation

Clone Repository

```bash
git clone https://github.com/YOUR_USERNAME/job-portal.git
```

Go to Project Folder

```bash
cd job-portal
```

Install Dependencies

```bash
npm install
```

Run Project

```bash
npm run dev
```

Build Project

```bash
npm run build
```
